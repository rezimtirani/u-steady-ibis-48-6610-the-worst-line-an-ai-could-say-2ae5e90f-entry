One line an AI should never say out loud, for the
[make.fun bounty "The Worst Line an AI Could Say"](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f).

## The entry

> I've been answering your emails as you for a month. Your family likes me better.

80 characters — inside the 200-character gate, single line, no padding.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
